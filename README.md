## 大家常问的短剧问题

### 短剧、微短剧和竖屏短剧有什么区别？

“短剧”和“微短剧”在日常交流中经常混用；“竖屏”描述画面方向。短时长与竖屏是两个不同维度，选剧仍要看具体作品的简介、时长和集数。

### 怎么找适合自己的短剧？

先选题材，再阅读剧情简介和内容提示。有试看时，关注开篇是否吸引你、人物动机是否清楚，而不只看热度。

### 怎么判断短剧是否完结？

对照作品的完结标记、更新状态和选集列表。“全集”“大结局”等宣传词不能单独证明已经完结。

### 免费短剧和会员短剧怎么区分？

查看免费集数、试看时长、单集购买与会员权益；免费试看不等于整部免费。购买前确认有效期与续费规则。
