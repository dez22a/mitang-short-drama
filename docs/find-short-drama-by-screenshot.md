# 只有一张截图怎么找短剧名字？

可以先用截图寻找候选作品，再用字幕和剧情核对。识图结果可能只是相似画面、同一演员的其他作品或转载片段，不能直接当作确定的剧名。

## 第一步：选一张信息足够的截图

优先保留清楚的字幕、独特场景或片头信息。能回到原片段时，可以另选一张不同场景的截图，供后面交叉比较。

| 截图里有什么 | 先用什么线索 |
| --- | --- |
| 片头或片尾出现标题 | 手动抄下标题，再核对作品简介 |
| 清楚的角色称呼和台词 | 提取文字，用角色名加独特台词搜索 |
| 有辨识度的场景、服装或道具 | 先识图寻找出处，再比较另一处场景 |
| 只有演员近景 | 作为辅助线索，不能只凭长相确定作品 |
| 账号水印或平台标识 | 回到原发布页面找简介和作品说明 |

搜索前裁掉聊天记录、通知和账号信息。保留字幕等找剧线索，不要为了只截人物而把有用文字一起裁掉。

## 第二步：用图片搜索找出处

可以使用 Google 智能镜头等图片搜索工具。以 Google 为例：

1. 打开 Google 搜索，选择搜索框中的智能镜头图标。
2. 上传自己保存的截图。
3. 先看包含相同画面的网页，再看相似图片。
4. 如果结果被边框、按钮或其他元素干扰，可以重新选择画面区域。

具体入口会随设备和版本变化，操作以 [Google 图片搜索官方帮助](https://support.google.com/websearch/answer/1325808?hl=zh-CN) 为准。图片搜索会将所选图片提交给搜索服务，因此只选需要用于找剧的画面。

## 第三步：把图片里的文字变成搜索词

识图找不到出处时，查看截图中的字幕、片名和角色称呼。文字识别可能把同音字、繁简体或人名识别错，搜索前应对照原图检查。

每次先组合两条有辨识度的线索，例如“角色名＋独特台词”，再加“短剧”。如果字幕只是“你怎么来了”这类常见对白，就换另一张有具体人物、地点或事件的画面。

有剧情线索时，可以接着使用[按台词、角色和剧情找短剧的方法](find-short-drama-by-plot.md)。

## 第四步：至少核对两类信息

打开候选作品的介绍页，比较剧情和人物关系，再核对截图中的场景、服装或另一句台词。同一演员参演多部作品，同一题材也可能有相似海报，仅凭一张脸或一个相近标题不够。

如果两张截图始终对应不同作品，原片段可能拼接了多部短剧，可以分开查找。找到名称后，再查看[全集与完结核对清单](complete-short-drama-checklist.md)，确认观看的是相应版本。

## 常见问题

### 截图很模糊，还能找到吗？

优先找回原视频，重新截取清晰画面。无法找回时，先手动整理能看清的字幕和场景；放大图片并不能保证恢复缺失的细节。

### 搜到了演员名字，就能确定剧名吗？

不能。可以把演员名作为新增线索，再与剧情、角色和画面比较，不要直接把该演员最热门的作品当作答案。

### 识图工具给出了一个剧名，可以直接去看吗？

先核对作品介绍与截图。识图、问答工具或网友提供的名称都可作为候选，确认前不要把它当成唯一答案，也不要为了获取剧名随意付款或安装陌生软件。
