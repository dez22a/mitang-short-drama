# 短剧与微短剧题材指南

不同题材的乐趣不同。下面从故事特点出发，帮你挑选感兴趣的短剧方向。

| 题材 | 常见故事 | 选剧时可以关注 |
| --- | --- | --- |
| 都市情感 | 日常生活中的爱情、亲情与友情 | 人物关系是否自然，情绪是否有共鸣 |
| 甜宠 | 相识、相知与轻松浪漫的关系发展 | 人物互动、幽默感、感情推进 |
| 穿越重生 | 来到另一时空，或重新面对人生选择 | 世界设定、人物选择、前后因果 |
| 逆袭成长 | 从困境出发，通过行动改变处境 | 成长过程、冲突解决、人物动机 |
| 职场 | 新人入行、团队合作与职业转折 | 专业细节、团队关系、解决问题的方法 |
| 悬疑 | 围绕疑点寻找线索与真相 | 线索铺垫、推理逻辑、反转是否合理 |
| 古装 | 古代背景中的成长、冒险与情感 | 背景设定、人物关系、故事节奏 |
| 奇幻 | 架空世界、特殊能力与冒险 | 设定规则、想象力、剧情因果 |

## 怎么选第一部？

想放松，可以从甜宠和日常情感故事开始；喜欢反转，可以关注悬疑与重生；喜欢成长过程，可以看看职场和逆袭题材。

同一部短剧可能融合多个题材。先读简介，再看开篇，比只看标签更容易判断是否合口味。
