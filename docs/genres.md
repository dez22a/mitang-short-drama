# 短剧题材介绍

以下为通用选剧参考，不是已上线剧目清单。

| 题材 | 常见故事 | 适合关注的看点 |
| --- | --- | --- |
| 都市成长 | 普通人在家庭、生活或事业中面对选择 | 人物成长、现实议题、选择的代价 |
| 温馨情感 | 亲情、友情与非露骨爱情故事 | 人物关系、情绪表达、相互理解 |
| 职场 | 新人入行、团队合作、职业转折 | 专业细节、解决问题、团队关系 |
| 悬疑 | 围绕疑点寻找线索与真相 | 线索是否公平、推理是否自洽 |
| 古装 | 古代背景下的成长、冒险与情感 | 世界设定、人物动机、故事节奏 |
| 奇幻 | 架空世界、特殊能力与冒险 | 设定规则、想象力、剧情因果 |

选择时先阅读简介和内容提示，再看少量开篇，判断节奏与题材是否适合自己。题材标签不能替代对具体内容的审核。
