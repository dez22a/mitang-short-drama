# 常见问题

## 这里能直接看短剧吗？

不能。本仓库只提供非露骨短剧的文字介绍与追剧指南，不托管视频。

## 观看入口在哪里？

当前尚未发布。独立的非露骨短剧专区及相关跳转页面核验后，会在 README 中补充。

## 为什么没有推荐片单？

具体剧目尚未完成内容核验，因此暂不列出剧名、封面或播放链接。现有题材介绍只是通用选剧参考。

## 是否全部免费观看？

本仓库文档可公开阅读。后续观看服务的价格、试看范围与会员权益，以核验后的站内实际说明为准；本仓库不承诺视频免费。

## 需要安装应用或注册账号吗？

阅读文档不需要安装应用或注册账号。后续观看入口的使用要求将在核验后说明。

## 会上传源代码或视频吗？

不会。本仓库仅维护介绍、指南与 FAQ，不上传业务源码、配置、凭据或视频文件。

## 如何反馈问题？

通过仓库 Issues 提交文字纠错或指南建议即可。请勿公开个人信息、支付信息或账号凭据。

## 多久更新一次？

根据已核验的信息更新，可通过提交记录查看变化。目前没有固定更新周期。
