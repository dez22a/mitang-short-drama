# 短剧一集几分钟？一部多少集？追完时间计算指南

搜索短剧时，经常会看到“80集”“100集”“一口气看完”等不同说法。短剧的集数多，不一定代表总时长很长；判断需要多久能追完，要同时看单集时长、总集数和版本形式。

## 短剧一集通常有多长？

短剧没有统一时长。同一部作品在不同页面上，还可能以单集、合并集或合集的形式出现。

| 页面形式 | 常见特点 | 查看时注意 |
| --- | --- | --- |
| 独立单集 | 每集单独排列，剧情衔接清楚 | 查看单集时长和是否连续 |
| 多集合并 | 几集被合成一个视频 | 核对标题里的集数范围 |
| 长视频合集 | 多集连续播放 | 确认是否包含片头片尾或重复内容 |
| 剧情解说 | 用旁白概括原剧情 | 这通常不是完整正片 |
| 精华剪辑 | 只保留部分情节 | 不能用来判断原剧总时长 |

因此，看到一个几十分钟的视频时，不要马上认定它就是整部全集。

## 一部短剧通常有多少集？

不同作品差异很大。判断总集数时，优先查看作品详情页的选集列表和更新状态。宣传标题中的“全集”“大结局”只能作为线索，不能替代选集信息。

如果页面标注“更新至60集”，表示当前可以看到第60集，但不一定已经完结；如果标注“全60集”并且选集连续，完整度会更容易核对。

## 怎么估算追完需要多久？

可以使用这个简单方法：

**预计观看时间 = 单集平均时长 × 可观看集数**

例如，一部短剧有60集，平均每集2分钟，正片大约需要120分钟。考虑片头、加载、暂停和选集切换，可以再预留10%到20%的时间。

| 集数 | 单集2分钟 | 单集3分钟 |
| --- | ---: | ---: |
| 40集 | 约80分钟 | 约120分钟 |
| 60集 | 约120分钟 | 约180分钟 |
| 80集 | 约160分钟 | 约240分钟 |
| 100集 | 约200分钟 | 约300分钟 |

这只是估算。实际时长还会受片头片尾、重复回顾和版本剪辑影响。

## 追剧前先检查四件事

1. 选集是否从第一集连续排列到最后一集。
2. 页面显示的是“更新至”还是“全剧完结”。
3. 视频是完整正片、合并播放，还是剧情解说。
4. 免费范围和后续观看方式是否说明清楚。

想一次看完整部作品时，先核对选集列表，再计算时间，会比只看标题更可靠。
