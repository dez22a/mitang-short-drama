# 追剧指南

## 选剧

1. 先确定想看的题材，阅读简介与内容提示。
2. 查看总集数、单集时长及更新状态，安排观看时间。
3. 如果有试看内容，先判断剧情和播放体验是否符合预期。

## 记录进度

记录剧名、已看集数和是否完结，避免重复寻找。平台如提供收藏或观看历史，可按实际功能使用；本仓库不提供账号、收藏或播放服务。

## 收费与观看

观看前查看具体剧集的免费范围、会员权益和费用说明。不要仅凭宣传语判断整部剧免费，也不要向非官方个人账号付款。

## 播放问题

出现无法播放时，可以检查网络、刷新页面或更新浏览器，并保留报错信息。涉及会员权益或支付问题，应通过经核验的官方支持渠道处理；不要在公开 Issues 中提交订单或账号信息。

## 分享与讨论

分享剧情时标注剧透，尊重作品版权，不上传未经授权的视频、字幕或下载资源。
