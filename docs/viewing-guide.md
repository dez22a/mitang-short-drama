# 短剧追剧指南｜选剧、看全集与记录进度

## 先选故事，再看热度

从自己喜欢的题材开始，阅读剧情简介和内容提示。热度可以作为参考，人物和故事是否吸引你更重要。

## 看清完结与更新状态

想连续看完，可以优先选择已完结的短剧；追连载时，先了解更新安排。观看前查看总集数和单集时长，给自己留出合适的时间。

## 按集数顺序观看

从第一集开始，留意选集列表和当前集数。遇到片段或预告时，先确认是否为正片，避免跳过关键剧情。

## 记录自己的追剧进度

记下剧名、已看集数和是否完结。观看平台如提供收藏与历史记录，可以用这些功能快速续看。

## 付费前看清说明

确认试看范围、单集费用或会员权益，按自己的需求选择。看清购买期限和自动续费说明，再决定是否购买。

## 分享时照顾还没看完的人

讨论结局或反转前标注“剧透”。推荐时说清题材和看点，让别人更容易判断是否感兴趣。
