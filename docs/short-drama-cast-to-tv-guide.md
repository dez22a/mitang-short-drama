# 短剧怎么投屏到电视？手机投屏方法与常见问题

想把手机里的短剧放到电视上看，先确认播放平台、手机和电视是否支持投屏。不同设备的按钮名称可能是“投屏”“无线显示”“屏幕镜像”或“AirPlay”。

## 投屏前先检查三件事

1. **手机和电视连接同一个 Wi-Fi**：很多设备只有在同一局域网内才能互相发现。
2. **电视已开启投屏功能**：在电视设置或应用列表里查找“无线投屏”“多屏互动”或“AirPlay”。
3. **短剧能在手机上正常播放**：先排除账号、网络和剧集本身无法播放的问题。

## 优先使用播放器里的投屏按钮

如果短剧播放页右上角有电视形状的投屏按钮，可以按下面的顺序操作：

1. 打开想看的短剧并开始播放。
2. 点击播放器里的投屏按钮。
3. 从设备列表中选择自己的电视。
4. 等待电视开始播放，再用手机选择剧集、暂停或调整进度。

这种方式通常只把视频传到电视，手机仍可做其他操作。部分平台或剧集会因播放授权、设备型号或系统版本而不支持投屏，应以播放页提示为准。

## 没有投屏按钮时怎么办

- **iPhone、iPad 与支持 AirPlay 的电视**：打开控制中心，选择“屏幕镜像”，再选择电视。
- **安卓手机与智能电视**：在手机快捷设置里寻找“无线投屏”“投射屏幕”或“多屏互动”。
- **电视盒子或投屏设备**：确认设备已经启动，并与手机处于同一网络。

屏幕镜像会把整个手机画面显示在电视上。观看前可打开横屏或全屏，并关闭可能弹出的私人通知。

## 常见问题排查

### 搜不到电视

先关闭再打开手机和电视的 Wi-Fi，确认两台设备不是分别连接访客网络和主网络。仍然搜不到时，重启电视的投屏功能，并检查电视系统是否有更新。

### 连接成功但电视黑屏

先退出投屏重新连接，再尝试播放器自带的投屏按钮。如果只有某部短剧黑屏，可能是该内容限制了屏幕镜像或当前设备不兼容，可以改用平台支持的设备观看。

### 画面卡顿或声音不同步

暂停几秒等待缓冲，减少同一网络中的大文件下载，并让手机、电视靠近路由器。也可以降低清晰度后重新投屏。

### 切换下一集后投屏断开

先在手机上切换到下一集，确认开始播放后再连接电视。连续出现时，可退出播放页重新进入，并记录出问题的剧名、集数和设备型号反馈给平台。
